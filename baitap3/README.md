1. Phân tích cách xử lý

Bảng giá:

Mã	Món	Giá
S	Size S	35.000
M	Size M	42.000
L	Size L	48.000
T	Topping	10.000
X	Món hủy	0

Các bàn:

Bàn 1: MLT
Bàn 2: SSX
Bàn 3: LLTT
Bàn 1
M = 42.000
L = 48.000
T = 10.000
----------------
Tạm tính = 100.000

Không trên 100.000 nên không giảm.

→ 100.000 VNĐ

Bàn 2
S = 35.000
S = 35.000
X = bỏ qua
----------------
Tạm tính = 70.000

→ 70.000 VNĐ

Bàn 3
L = 48.000
L = 48.000
T = 10.000
T = 10.000
----------------
Tạm tính = 116.000

Hóa đơn > 100.000 nên giảm 10%:

116.000 × 0.9 = 104.400

→ 104.400 VNĐ

Tổng doanh thu ca
100.000 + 70.000 + 104.400
= 274.400 VNĐ
